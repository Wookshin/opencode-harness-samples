# `_workspace` — 단계 사이의 우편함

이 폴더는 **Phase 간 산출물이 오가는 곳**입니다.
에이전트끼리 직접 대화할 수 없으므로(각자 별도 세션에서 일합니다), **파일로 주고받습니다.**

## 규약

| 규칙 | 내용 |
|---|---|
| 파일명 | `<순번>-<단계>[-<식별자>].md` — 예: `1-plan.md`, `2-impl-a.md` |
| 쓰기 | 각 에이전트는 **자기 파일 하나만** 씁니다. 남의 파일을 고치지 않습니다 |
| 읽기 | 다음 단계는 앞 단계 **파일을 직접 읽습니다.** 내용을 프롬프트로 받지 않습니다 |
| 진행판 | `STATUS.md` 는 오케스트레이터만 갱신합니다 |

## 왜 이렇게 하나

1. **컨텍스트 절약** — 계획서 전문을 프롬프트에 붙이는 대신 경로 한 줄만 넘깁니다.
2. **감사 흔적** — 무슨 일이 있었는지 파일로 남습니다. 실패해도 어디서 틀어졌는지 보입니다.
3. **재개 가능** — 중간에 끊겨도 이 폴더만 보면 이어서 할 수 있습니다.
4. **병렬 안전** — 동시에 도는 에이전트들이 각자 다른 파일에 쓰므로 충돌하지 않습니다.

## 권한과의 관계

리뷰어·검증자처럼 **소스는 못 고치는** 에이전트도 여기에는 써야 합니다.
그래서 이렇게 열어 둡니다.

```yaml
permission:
  edit:
    "*": deny              # 소스 코드는 못 고침
    "*_workspace/*": allow # 자기 보고서는 쓸 수 있음
```

> 패턴은 **git 저장소 루트 기준 상대 경로**와 매칭되고, `*` 는 `/` 를 넘어갑니다.
> 그래서 `_workspace/*` 가 아니라 `*_workspace/*` 로 써야 `05-.../_workspace/...` 도 잡힙니다.

## 정리하기

이 폴더의 산출물은 `.gitignore` 에 들어 있어 커밋되지 않습니다.
처음 상태로 되돌리려면:

```bash
rm -f _workspace/*.md
```

(이 README.md 는 규약 설명이라 유지됩니다)
