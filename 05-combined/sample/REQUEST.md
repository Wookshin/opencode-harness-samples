# 기능 요청

`todo.js` 에 아래 **두 기능**을 추가해 주세요.

## 1. 완료 표시

```bash
node todo.js done 2
```

- 2번 항목을 완료 상태로 바꿉니다.
- 이미 완료된 항목이면 그렇다고 알려 줍니다.
- 없는 번호면 오류 안내를 합니다.
- `list` 출력에서 완료 항목은 `[x]`, 미완료는 `[ ]` 로 보여야 합니다.

## 2. 통계 보기

```bash
node todo.js stats
```

아래 형식으로 출력합니다.

```
전체 5개 · 완료 2개 · 남음 3개 (40%)
```

- 항목이 하나도 없으면 `할 일이 없습니다` 만 출력합니다.
- 퍼센트는 소수점 없이 반올림합니다.

## 조건

- 외부 라이브러리를 쓰지 마세요. `node todo.js` 로 바로 돌아가야 합니다.
- 기존 `add` / `list` 동작을 바꾸지 마세요.
- 저장 파일 형식(`todos.json`)을 바꾸지 마세요. 기존 데이터가 그대로 읽혀야 합니다.
