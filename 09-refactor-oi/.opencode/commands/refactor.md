`$ARGUMENTS` 가 **대상 소스 경로**입니다 (예: `YOEDSMOV`, `src/Screens/YOEDSMOV`, 저장소 전체는 `.`).

비어 있으면 **묻고 멈추세요.** 임의로 저장소 전체를 잡지 마세요 — 규모가 커서 리포트가 못 쓰게 됩니다.

작업 폴더는 `_workspace/scan-<slug>` 입니다. slug 는 경로의 영숫자 아닌 것을 `-` 로 바꾼 것,
`.` 은 `root` 입니다.

Phase 0 부터 4 까지 순서대로 진행하세요.

- **Phase 2 의 네 제안자는 한 응답에서 함께** 부릅니다. 나눠 부르면 직렬이 됩니다.
- 모든 `task` 프롬프트에 **작업 폴더 전체 경로**를 적습니다. 서브에이전트는 대화를 못 봅니다.
- 프롬프트에는 **경로만** 넘깁니다. 파일 내용을 붙여 넣지 마세요.
- `[N/4 …]` 로 진행을 알립니다.
- **Phase 3.5 의 로드맵은 당신이 직접 씁니다.** 위임하지 마세요.
- 마지막에 **HTML 이 실재하는지 `read` 로 확인**하고, 그 경로를 보고 맨 앞에 놓으세요.

규모가 파일 200개 또는 30,000줄을 넘으면 **멈추고 경로를 좁히라고 요구하세요.**
