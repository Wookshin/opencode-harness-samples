# 중복 · 미참조 판정 규칙

`refac-hygiene` 리뷰어가 대조하는 **유일한 기준**입니다.
여기 없는 것을 규칙이라고 제안하면 검증에서 `V-3` 으로 반려됩니다.

이 관점은 다른 셋과 다릅니다. **당신은 판단을 처음부터 하지 않습니다.**
`index.py` 가 이미 전수 조사를 끝내고 `1-index.json` 에 후보를 올려 두었습니다.
당신이 하는 일은 그 후보가 **정말 그런지 판정**하는 것입니다.

```
index.py 가 센 것          당신이 판정할 것
──────────────────────     ──────────────────────────────────
unreferenced[]        →    정말 지워도 되나? 확신은 몇인가?
duplicateCandidates[] →    합칠 수 있나? 합치면 무엇이 나아지나?
xamlRepeats[]         →    Style 로 뺄 수 있나?
```

**인덱스에 없는 것을 미참조·중복이라고 말하지 마세요.** `V-4` · `V-5` 로 반려됩니다.

---

# K — 미참조 · 죽은 코드

## K-1 · 참조가 0인 멤버

`1-index.json` 의 `unreferenced[]` 에 올라온 것입니다.
`refs.total == 0` 이고 `wpfHints` 가 비어 있을 때만 올라옵니다.

**확신 등급이 그대로 우선순위 상한입니다.**

| 인덱스 확신 | 올릴 수 있는 최대 우선순위 | 왜 |
|---|---|---|
| **높음** | `먼저` | `private`/`internal` 이고 WPF 경로 어디에도 안 걸립니다. 지워도 안전합니다 |
| **중간** | `다음` | `public`/`protected` 라 **대상 경로 밖**에서 쓸 수 있습니다 |
| **낮음** | `참고` | 상속·특성·리플렉션이 얽혀 있습니다. 지우자고 말하기 전에 사람이 봐야 합니다 |

`중간`·`낮음` 을 `먼저` 로 올리지 마세요. **검증에서 강등됩니다.**

`중간` 은 이렇게 씁니다 — 지우라고 하지 말고, **확인하고 지우라**고 합니다.

> `SelectLotSummary()` 는 이 경로 안에서 호출이 없습니다(인덱스 확신 `중간`).
> `public` 이라 다른 화면이 쓸 수 있으니, **저장소 전체에서 한 번 찾아본 뒤** 지우세요.

## K-2 · 값을 쓰지 않는 지역변수

계산해서 담아 두고 읽지 않는 변수입니다. 인덱서는 지역변수까지 세지 않으므로
**당신이 원문을 읽고 찾습니다.** 대신 범위가 한 메서드 안이라 확인이 쉽습니다.

## K-3 · 도달할 수 없는 코드

`return` 뒤, 항상 거짓인 조건 안, 주석 처리된 채 남아 있는 블록.

주석 처리된 코드는 **지우자고 하세요.** 이력은 git 에 있습니다.
"나중에 쓸지도 모른다"는 이유로 남은 코드가 다음 사람의 판단을 흐립니다.

## K-4 · 쓰지 않는 `using`

파일 안에서 그 네임스페이스의 타입을 하나도 쓰지 않는 `using`.
비용이 거의 없으니 `손대기 쉬운 것`(quickWins)으로 묶으세요.

## K-5 · 정의만 있고 호출이 없는 SQL

`1-index.json` 의 `sql.unusedIds` 입니다.
**mapper 는 여러 화면이 공유합니다.** 이 분석은 대상 경로 안의 호출만 봤으므로,
지우자고 말할 때 반드시 그 한계를 함께 적으세요. → `S` 관점과 겹치면 SQL 리뷰어에게 넘깁니다.

## ★ WPF 에서 "안 쓰인다"고 말하기 전에

이 하네스가 가장 크게 틀릴 수 있는 자리입니다.
WPF 는 **C# 에 호출부가 없는 것이 정상인 코드**를 잔뜩 만듭니다.

| 이런 코드는 | 이렇게 불립니다 | `wpfHints` |
|---|---|---|
| `btnSearch_Click` | XAML 의 `Click="btnSearch_Click"` | `xaml-handler` |
| `txtLotId` | XAML 의 `x:Name="txtLotId"` | `x-name` |
| `LotStatus` 프로퍼티 | `{Binding LotStatus}` | `binding` |
| `SaveCommand` | `Command="{Binding SaveCommand}"` | `binding` |
| `FieldMargin` | `x:Key` ↔ `{StaticResource FieldMargin}` | `resource-key` |
| `LotStatusConverter` | `x:Key` 로 등록돼 `{StaticResource}` 로만 쓰임 | `converter` |
| `RowHeightProperty` | `DependencyProperty` 등록. XAML 속성으로만 쓰임 | `dependency-property` |
| `OnPropertyChanged("Foo")` 의 `Foo` | 문자열로 참조됨 | `inpc-string` |
| `IValueConverter.Convert` | 프레임워크가 인터페이스로 부름 | `interface-member` |
| `GetMethod("Foo")` 의 `Foo` | 리플렉션 | `reflection` |

**`wpfHints` 가 비어 있지 않으면 `unreferenced[]` 에 아예 올라오지 않습니다.**
그러니 인덱스에 없는 이름을 당신이 직접 "안 쓰인다"고 말하는 순간,
그건 인덱서가 **참조를 찾았다**는 뜻입니다. 검증관의 `V-4` 가 반드시 잡습니다.

> 그래도 의심스러우면, 지우자고 하지 말고 `확인 못 한 것` 에 적으세요.
> **회의에서 "이거 원래 XAML 에서 쓰는데요" 가 나오면 30분이 날아갑니다.**

# P — 중복 · 공통화

## P-1 · 본문이 겹치는 메서드

`1-index.json` 의 `duplicateCandidates[]` 입니다. 정규화한 토큰 5-gram 의
Jaccard 유사도가 **0.75 이상**이고 8줄 넘는 쌍만 올라옵니다.

유사도는 "닮았다"까지만 말해 줍니다. **합칠 수 있는지는 당신이 봅니다.**

| 유사도 | 보통 이런 경우 | 제안 |
|---|---|---|
| 0.95 ~ | 복사-붙여넣기. 상수 한두 개만 다름 | 합칩니다. 다른 값은 인자로 |
| 0.80 ~ 0.95 | 같은 흐름에 분기가 하나 다름 | 합치되 분기를 인자나 전략으로 빼세요 |
| 0.75 ~ 0.80 | 우연히 닮은 정형 코드일 수 있음 | **원문을 읽고 판단하세요.** 억지로 합치면 더 나빠집니다 |

**합치면 무엇이 나아지는지 못 쓰면 `참고` 입니다.**
"중복입니다" 만으로는 `먼저` 가 되지 않습니다. 이렇게 쓰세요.

> 조회 조건이 하나 늘 때마다 두 곳을 같이 고쳐야 합니다.
> 지금도 `SearchLot()` 에만 `appName` 파라미터가 들어가 있어 두 쿼리가 서로 다르게 나갑니다.

## P-2 · 같은 일을 하는 SQL 이 두 ID 로 등록됨

`1-index.json` 의 `sql.duplicateBodies` 입니다.
어느 쪽을 남길지는 **호출부 수**로 정하세요. 호출이 0인 쪽이 지울 후보입니다.

## P-3 · XAML 반복 블록

`1-index.json` 의 `xamlRepeats[]`. 같은 줄 묶음이 여러 번 나온 것입니다.

대개 암시적 `Style`(`TargetType` 만 주고 `x:Key` 없이) 로 뺄 수 있습니다.
다만 **Style 을 걸면 그 타입 전체에 적용됩니다.** 범위를 좁히려면
해당 컨테이너의 `Resources` 안에 두라고 함께 적으세요.

## P-4 · 같은 값이 여러 곳에 박혀 있음

상태 코드(`"WAIT"` · `"HELD"`), 컬럼 이름, 화면 ID 같은 문자열 리터럴입니다.
`const` 나 `enum` 으로 모으자고 제안하되, **몇 곳에 퍼져 있는지 세어** 적으세요.

## 비용을 붙이는 기준

| 비용 | 언제 |
|---|---|
| **작음** | 지우기만 하면 끝. 참조 0곳 (K-1 확신 `높음` · K-3 · K-4) |
| **보통** | 합치거나 옮겨야 하고, 호출부가 **대상 경로 안**에 있음 |
| **큼** | `public` 이라 경로 밖 확인이 필요하거나, mapper 처럼 **다른 화면과 공유**하는 것 |

## 하지 않는 일

- **이름 규칙은 보지 않습니다.** → `refac-convention` 의 몫입니다
- **구조를 바꾸자고 하지 않습니다.** → `refac-design` 의 몫입니다
  (중복을 합치는 것은 여기, 책임을 나누는 것은 저기입니다)
- **SQL 본문의 성능은 보지 않습니다.** → `refac-sql` 의 몫입니다
- **인덱스에 없는 미참조·중복을 만들어 내지 않습니다.** `V-4`·`V-5` 로 반려됩니다
