`_workspace/` 아래의 **모든 작업 폴더**를 읽고 진행 상황을 정리해 주세요.

1. **목록은 스크립트가 만듭니다.** 이 한 줄이면 끝입니다.

   ```bash
   python .opencode/skills/code-review-oi-pr/assets/ws.py --list
   ```

   폴더를 직접 뒤지지 마세요. `ls` 는 PowerShell 에서 통하지 않고, `list` 도구는
   없는 환경이 있으며, `glob` 은 숨김 경로를 건너뜁니다. 스크립트는 셋 다 안 탑니다.
   `python` 이 안 먹히면 `py`(Windows) 또는 `python3` 입니다.
2. 더 자세히 볼 폴더가 있으면 그 폴더의 `STATUS.md` 를 `read` 로 읽습니다.
   **`STATUS.md` 가 없어도 정상입니다** — 위 표는 파일 존재로 판정한 것이라 그게 사실입니다.
3. 아래 표로 정리합니다.

```
| 작업 폴더 | PR | 마지막 Phase | 확인사항 | 리포트 |
|---|---|---|---|---|
| pr-1234 | #1234 EDS 반출 다건 확정 | 4 리포트 완료 | 14건 (꼭 확인 6) | review-1234.html |
| pr-5678 | #5678 재고 조회 필터 추가 | 2 리뷰 진행 중 | — | — |
```

각 폴더마다 아래도 덧붙입니다.

- 어떤 산출물이 있는지 (없는 단계가 어디부터인지)
- 이어서 하려면 무슨 커맨드를 쳐야 하는지 (`/review-pr <번호>` 로 재개, `/report-only <번호>` 로 HTML 만)
- `.prev-*` 로 밀어 둔 이전 실행이 있으면 그 사실도

작업 폴더가 하나도 없으면 "진행 중인 리뷰가 없습니다" 한 줄로 끝냅니다.

**아무 작업도 실행하지 마세요.** 읽고 보고만 합니다. 에이전트를 부르지 말고,
파일을 만들거나 지우거나 옮기지도 마세요.
