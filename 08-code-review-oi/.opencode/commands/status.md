`_workspace/` 아래의 **모든 작업 폴더**를 읽고 진행 상황을 정리해 주세요.

1. **`list` 도구로** `_workspace/` 의 작업 폴더 목록을 구합니다 (`pr-*`).
   `README.md` 는 규약 문서이니 제외합니다. 셸 명령(`ls`)을 쓰지 마세요 —
   팀 환경이 PowerShell 이라 통하지 않습니다.
2. 각 폴더의 `STATUS.md` 와 실제 파일 목록을 읽습니다.
3. 아래 표로 정리합니다.

```
| 작업 폴더 | PR | 마지막 Phase | 판정 | 리포트 |
|---|---|---|---|---|
| pr-1234 | #1234 EDS 반출 다건 확정 | 4 리포트 완료 | FAIL | review-1234.html |
| pr-5678 | #5678 재고 조회 필터 추가 | 2 리뷰 진행 중 | — | — |
```

각 폴더마다 아래도 덧붙입니다.

- 어떤 산출물이 있는지 (없는 단계가 어디부터인지)
- 이어서 하려면 무슨 커맨드를 쳐야 하는지 (`/review-pr <번호>` 로 재개, `/report-only <번호>` 로 HTML 만)
- `.prev-*` 로 밀어 둔 이전 실행이 있으면 그 사실도

작업 폴더가 하나도 없으면 "진행 중인 리뷰가 없습니다" 한 줄로 끝냅니다.

**아무 작업도 실행하지 마세요.** 읽고 보고만 합니다. 에이전트를 부르지 말고,
파일을 만들거나 지우거나 옮기지도 마세요.
