다음 PR 을 리뷰하세요: $ARGUMENTS

인자가 비어 있으면 사용자에게 PR 번호를 물어보고 멈추세요. 짐작하지 마세요.

**작업 폴더는 `_workspace/pr-<번호>` 입니다.** Phase 0 에서 먼저 확정하고 사용자에게 알리세요.
다른 PR 리뷰가 옆 폴더에서 동시에 돌고 있을 수 있으니, 그 폴더 밖에는 아무것도 쓰지 마세요.

Phase 0~4 를 **순서대로 전부** 수행하세요.

- Phase 2 의 리뷰어 3인은 **반드시 한 응답 안에서 동시에** 띄우세요.
- 단계 사이는 작업 폴더의 파일로 이으세요. 내용을 프롬프트에 복사하지 마세요.
  다만 **경로는 `_workspace/pr-<번호>/…` 전체 경로로** 적으세요 — 서브에이전트는 당신의 대화를 못 봅니다.
- 각 Phase 시작 시 `[N/4 단계명]` 형식으로 한 줄 알려 주세요.

마지막에 **`_workspace/pr-<번호>/review-<번호>.html` 이 실제로 만들어졌는지 확인**하고,
그 경로를 최종 보고의 맨 위에 적으세요. 이 파일이 이 하네스의 결과물입니다.
