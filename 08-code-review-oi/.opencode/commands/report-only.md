리뷰를 다시 하지 말고 **HTML 만 다시 만드세요.** 대상 PR: $ARGUMENTS

1. **작업 폴더를 정합니다.**
   - 인자가 있으면 → `_workspace/pr-<번호>`
   - 인자가 비어 있으면 → `list` 도구로 `_workspace/` 의 작업 폴더 목록을 보여 주고
     **어느 PR 인지 물어본 뒤 멈춥니다.** 임의로 고르지 마세요.
     여러 PR 리뷰가 동시에 진행 중일 수 있습니다.
2. 그 폴더에 `1-hunks.md` · `2-review-*.md` · `3-verify.md` 가 다 있는지 확인합니다.
   하나라도 없으면 **무엇이 없는지 알리고 멈추세요.** 없는 단계를 대신 수행하지 마세요.
3. `report-builder` 를 불러 그 폴더의 `4-findings.json` 과 HTML 을 다시 생성합니다.
   프롬프트에 **작업 폴더 전체 경로**를 명시하세요.
4. 파일이 만들어졌는지 확인하고 경로와 크기를 보고합니다.

템플릿이나 스크립트를 고친 뒤 결과를 다시 뽑을 때 쓰는 커맨드입니다.
같은 입력으로 두 번 돌리면 **같은 HTML 이 나와야 합니다.**
