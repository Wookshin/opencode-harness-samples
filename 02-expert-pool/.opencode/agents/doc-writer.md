```js
// 나쁨 — 코드가 이미 말하고 있음
// i를 1 증가시킨다
i++

// 좋음 — 코드가 말하지 않는 것
// 재고 API가 1-based 인덱스를 쓴다. 0-based로 보내면 항상 한 칸 밀린다.
i++
```
