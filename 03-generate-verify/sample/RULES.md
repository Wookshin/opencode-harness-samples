# 숫자야구 게임 규칙

`game-builder` 와 `game-verifier` 모두 이 문서를 기준으로 삼습니다.
**이 파일은 수정 대상이 아닙니다.**

## 게임 규칙

1. 컴퓨터가 **1~9 사이 서로 다른 숫자 3개**로 정답을 만듭니다. (0은 쓰지 않습니다)
2. 플레이어가 3자리 숫자를 추측합니다.
3. 판정:
   - **스트라이크** — 숫자와 위치가 모두 맞음
   - **볼** — 숫자는 있으나 위치가 다름
   - **아웃** — 맞는 숫자가 하나도 없음 (`0S0B` 대신 `아웃` 으로 표시)
4. `3S` 가 되면 정답이며 게임이 끝납니다.

## 입력 검증

아래 입력은 **오답 처리가 아니라 오류 안내** 후 다시 입력받아야 합니다. 시도 횟수에 포함하지 않습니다.

| 잘못된 입력 | 예 |
|---|---|
| 3자리가 아님 | `12`, `1234` |
| 숫자가 아닌 문자 포함 | `12a` |
| 중복된 숫자 | `112` |
| 0 포함 | `102` |

## 검증 인터페이스 (반드시 지킬 것)

자동 검증이 가능하도록 아래 두 가지를 **정확히** 지원해야 합니다.

### 1. 판정 함수를 내보낼 것

```js
module.exports = { judge, makeAnswer }
```

- `judge(answer, guess)` — 두 인자 모두 3자리 **문자열**. 아래 형태의 객체를 반환합니다.
  ```js
  { strike: 1, ball: 1 }
  ```
- `makeAnswer()` — 규칙 1을 만족하는 3자리 **문자열**을 반환합니다.

### 2. 정답을 고정할 수 있을 것

환경변수 `BASEBALL_ANSWER` 가 설정되어 있으면 **그 값을 정답으로 사용**합니다.

```bash
BASEBALL_ANSWER=123 node game.js
```

이게 있어야 검증자가 결과를 예측하고 확인할 수 있습니다.

## 합격 기준

아래 **전부**를 만족해야 `PASS` 입니다. 하나라도 어긋나면 `FAIL` 입니다.

| # | 기준 | 확인 방법 |
|---|---|---|
| 1 | `node game.js` 가 오류 없이 시작된다 | 실행 |
| 2 | `makeAnswer()` 가 1~9의 서로 다른 3자리를 만든다 | 20회 이상 호출해 검사 |
| 3 | `judge("123","123")` → `{strike:3, ball:0}` | 함수 직접 호출 |
| 4 | `judge("123","132")` → `{strike:1, ball:2}` | 함수 직접 호출 |
| 5 | `judge("123","456")` → `{strike:0, ball:0}` | 함수 직접 호출 |
| 6 | `judge("123","231")` → `{strike:0, ball:3}` | 함수 직접 호출 |
| 7 | `BASEBALL_ANSWER` 로 정답을 고정할 수 있다 | 환경변수 설정 후 실행 |
| 8 | 잘못된 입력 4종을 모두 오류 안내 후 재입력받는다 | 각각 입력해 확인 |
| 9 | `3S` 도달 시 게임이 종료된다 | 정답 고정 후 정답 입력 |

## 참고

- 표준 입력을 읽는 부분은 Node 내장 `readline` 으로 충분합니다.
- 외부 라이브러리를 쓰지 마세요. `node game.js` 로 바로 돌아가야 합니다.
