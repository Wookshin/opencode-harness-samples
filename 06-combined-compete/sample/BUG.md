# 버그 리포트

## 증상

기간을 합산하면 값이 터무니없이 큽니다.

```js
const { sumDurations } = require('./sample/parser.js')

sumDurations(['1h', '30m'])   // 기대: 90    실제: 90      ← 이건 맞음
sumDurations(['1h30m'])       // 기대: 90    실제: 6030    ← 틀림
sumDurations(['2h15m'])       // 기대: 135   실제: 12015   ← 틀림
```

**단위가 하나만 있는 문자열은 맞는데, 두 개 이상 붙어 있으면 틀립니다.**

## 재현 조건

- `parseDuration("1h30m")` 처럼 **한 문자열에 단위가 둘 이상** 들어간 경우
- 단위가 하나면 정상

## 기대 동작

| 입력 | 기대값 (분) | 현재 실제값 |
|---|---|---|
| `"45m"` | 45 | 45 ✅ |
| `"1h"` | 60 | 60 ✅ |
| `"1h30m"` | 90 | **6030** ❌ |
| `"2h15m"` | 135 | **12015** ❌ |
| `"2d"` | 2880 | 2880 ✅ |
| `"1d2h30m"` | 1590 | **144012030** ❌ |
| `""` | 0 | 0 ✅ |
| `"abc"` | 0 | 0 ✅ |

## 영향

일정 합산 화면에 표시되는 총 소요 시간이 전부 잘못 나옵니다.
