# 01 · 파이프라인 (Pipeline)

> **한 줄로**: 앞 단계의 결과가 다음 단계의 입력이 되는 직렬 흐름.

## 바로 실행하기

```bash
cd 01-pipeline
opencode run "/translate sample/article.md"
```

끝나면 `sample/article.ko.md` 가 생깁니다.

TUI로 단계별 진행을 보고 싶다면:

```bash
cd 01-pipeline
opencode
# 그다음 입력창에  /translate sample/article.md
```

## 무엇을 보여주는 샘플인가

영어 문서를 **세 사람이 차례로** 번역합니다. 한 명에게 "잘 번역해 줘"라고 시키는 것과 무엇이 다른지 보는 게 목적입니다.

| 단계 | 담당 | 모델 | 하는 일 | 하지 않는 일 |
|---|---|---|---|---|
| 1 | `translator` | 저렴 | 빠짐없이 옮기기 | 다듬기 |
| 2 | `reviewer` | 무난 | 원문 대조, 오역·누락 잡기 | 문체 손대기 |
| 3 | `polisher` | 무난 | 자연스러운 한국어로 | 의미 바꾸기 |

각 단계가 **자기 일만** 하도록 프롬프트에 "하지 않는 일"을 명시한 것이 핵심입니다. 한 명에게 전부 시키면 "다듬다가 의미가 바뀌는" 사고가 납니다.

## 패턴이 보이는 지점

### ① 단계 사이 인계는 오케스트레이터가 손으로 한다

`.opencode/agents/pipeline-lead.md` 를 열어 보세요.

> **서브에이전트들은 서로의 대화를 볼 수 없습니다.** 각자 별도 세션에서 일하기 때문입니다.
> 따라서 다음 단계에 필요한 내용은 **당신이 프롬프트에 직접 담아** 전달해야 합니다.

이게 파이프라인의 핵심 제약입니다. OpenCode에는 에이전트끼리 결과를 주고받는 통로가 없습니다. `translator` 의 출력을 `reviewer` 의 프롬프트에 **문자열로 붙여 넣는 것**은 오케스트레이터의 일입니다.

### ② 2단계는 원문까지 같이 받는다

감수자는 "번역문만" 받으면 대조할 대상이 없습니다. 그래서 오케스트레이터가 `<원문>` 과 `<초벌번역>` 을 **둘 다** 넘깁니다. 파이프라인에서 흔히 놓치는 부분입니다 — 뒷단계가 앞단계 입력도 필요로 하는 경우.

### ③ 출력 형식을 고정했다

`reviewer` 는 `## 수정된 번역문` / `## 수정 내역` 두 섹션으로만 답하게 돼 있습니다.
오케스트레이터가 3단계에 넘길 때 **앞 섹션만 뽑아 쓰기** 위해서입니다. 위임 결과는 마지막 텍스트 한 덩어리로만 올라오므로, 형식을 고정하지 않으면 파싱할 수가 없습니다.

### ④ 모델을 단계별로 다르게 썼다

초벌은 저렴한 모델로 충분합니다. 판단이 필요한 감수·윤문만 무난한 모델을 씁니다.
`.opencode/agents/*.md` 의 `model:` 한 줄로 정해집니다.

## 직접 바꿔 보기

- **`polisher` 의 "절대 하지 않는 일"을 지워 보세요.** 윤문 단계에서 의미가 슬쩍 바뀌기 시작합니다.
- **2단계 프롬프트에서 `<원문>` 을 빼 보세요.** 감수자가 대조할 게 없어 오역을 못 잡습니다.
- **`translator` 의 모델을 무난한 것으로 올려 보세요.** 결과 차이 대비 비용이 얼마나 늘어나는지 확인해 보면 계층을 나누는 이유가 보입니다.
- **단계를 하나 더 붙여 보세요.** 예: `terminology` 에이전트를 만들어 용어집을 먼저 뽑고, 그걸 1~3단계 프롬프트에 모두 끼워 넣기.

## 파일 구조

```
01-pipeline/
├── opencode.jsonc              모델 기본값 · 권한 · subagent_depth
├── .opencode/
│   ├── agents/
│   │   ├── pipeline-lead.md    오케스트레이터 (primary) ← 여기가 핵심
│   │   ├── translator.md       1단계 (subagent, 저렴)
│   │   ├── reviewer.md         2단계 (subagent, 무난)
│   │   └── polisher.md         3단계 (subagent, 무난)
│   └── commands/
│       └── translate.md        /translate 커맨드
└── sample/
    └── article.md              번역할 영문 샘플
```
